# Los paquetes que el instalador le pasa a archinstall en `packages`.
#
# Formato: un paquete por línea; `#` comenta hasta el fin de línea; las líneas
# vacías se ignoran. Lo lee `archconfig.rs` en tiempo de ejecución desde
# /usr/share/vasak-installer/paquetes.txt — **no está compilado dentro del
# binario**, así que sumar un paquete al escritorio no obliga a recompilar el
# instalador ni a rehacer la ISO.
#
# El escritorio entero es el metapaquete `vasakos-desktop`, que sale del
# repositorio propio y arrastra por dependencia los 255 paquetes que forman
# VasakOS. Antes esa lista estaba escrita acá entera y otra vez en
# `archiso/packages.x86_64` —lo que la ISO instala en el medio live—, en dos
# repositorios distintos y sincronizadas a mano: sumar un paquete y olvidarse
# de la otra lista daba una ISO en la que algo andaba y un sistema instalado en
# el que no. Sumar un paquete al escritorio ahora es editarle las `depends` al
# metapaquete en `PKGBUILDS/vasakos-desktop/`; este archivo no cambia.

# EL ESCRITORIO
vasakos-desktop

# KERNEL
#
# No está en el metapaquete porque es una elección, y acá se nombra igual
# aunque archinstall instale el kernel por su propio campo `kernels`: nombrarlo
# de nuevo no cuesta nada —pacman saltea lo que ya está— y deja el archivo
# legible como «lo que tiene el sistema instalado». Los encabezados sí hacen
# falta: archinstall no los instala, y `broadcom-wl-dkms` compila su módulo
# contra ellos.
linux
linux-headers

# FUENTES QUE NO VAN EN LA ISO
#
# `noto-fonts-extra` son 331 MB y era el paquete más grande de la imagen. No
# está en las `depends` de `vasakos-desktop` a propósito: ahí lo heredaría
# también el medio live, que no lo necesita para instalar.
#
# Sacarlo no pierde cobertura de ningún idioma —son variantes de peso y ancho de
# las mismas familias, no alfabetos; los alfabetos están en `noto-fonts`— pero
# sí es lo que hace que un escritorio instalado tenga la tipografía completa.
# Por eso va acá: esta lista es la del sistema instalado.
noto-fonts-extra

# `fastfetch` imprime el resumen del sistema. No hace falta para instalar, así
# que no tiene por qué ocupar lugar en la imagen, pero sí es lo que alguien
# espera encontrar en su terminal recién instalada.
fastfetch

# LOS PROVEEDORES QUE ELEGIMOS NOSOTROS
#
# Estos tres ya vienen con el metapaquete, y sin embargo se nombran acá. No es
# repetición al descuido: son los que satisfacen una **dependencia virtual** con
# más de un proveedor, y pacman resuelve eso buscando primero entre los paquetes
# pedidos **como objetivo**. Las dependencias de un objetivo no cuentan para esa
# búsqueda, así que estar dentro de `vasakos-desktop` no alcanza.
#
# Cuando ninguno es objetivo, pacman elige por orden de repositorio y después
# alfabético. Eso ya rompió una instalación:
#
#   jack  →  eligió `jack2`, que conflictúa con `pipewire-jack`, y pacstrap
#            murió con «unresolvable package conflicts detected» **después** de
#            haber formateado el disco. Comprobado en una raíz vacía: pedir sólo
#            ffmpeg trae jack2; pidiendo pipewire-jack como objetivo, trae el
#            que corresponde.
#
# `mesa` y `mkinitcpio` hoy se resuelven bien **de casualidad**: `mkinitcpio`
# está en `core`, que se mira antes que `extra`, y `mesa` le gana por la eme a
# los siete proveedores de `opengl-driver`, que incluyen los de nvidia. Van
# fijados igual, porque de eso dependen que el equipo arranque y que la pantalla
# dibuje: no es algo que deba quedar librado a que nadie publique un paquete que
# ordene antes.
mesa
mkinitcpio
pipewire-jack

# LA FUENTE DE BASE
#
# `noto-fonts` ya viene con el metapaquete, y sin embargo se nombra acá. No es
# una repetición al descuido: pacman resuelve `ttf-font` —una dependencia
# virtual que tienen Firefox y otros navegadores— buscando primero entre los
# paquetes que se le pidieron **como objetivo**. Las dependencias de un objetivo
# no cuentan para eso, así que `noto-fonts` metido dentro de `vasakos-desktop`
# no alcanza, y pacman elegía por su cuenta el primero de once proveedores.
#
# Comprobado en una raíz vacía: pedir sólo Firefox instala `gnu-free-fonts`, que
# no eligió nadie; pidiendo `noto-fonts` como objetivo, usa ése y el otro no
# aparece.
#
# Y es `noto-fonts` porque es la fuente que el escritorio configura de verdad:
# `gtk-font-name=Noto Sans` en los ajustes de GTK que instala
# vasak-desktop-settings.
noto-fonts
